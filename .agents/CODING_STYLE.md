# Coding Style

## Naming

Hooks:

useSomething.ts

Utilities:

somethingUtils.ts

Factories:

somethingFactory.ts

Constants:

constants.ts

---

## Components

Keep components small.

Avoid giant files.

Prefer:

Component
Hook
Utility

separation.

---

## Imports

Order:

1. React
2. External libs
3. Types
4. Hooks
5. Utils
6. Constants

---

## Functions

Prefer:

pure functions

Avoid:

hidden side effects

---

## TypeScript

Always type:

- parameters
- returns
- state

Avoid:

any
